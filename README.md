# Repository structure

- [frontend](frontend) - it contains a todo-app frontend layer written with Quasar and Vue.js
- [backend-nodejs](backend-nodejs) - it's the backend side for the backend part written in TypeScript using Serverless,
  AWS Lambda, DynamoDB
- [backend-kotlin](backend-kotlin) - it's a backend with the same endpoints and infra as backend-nodejs, but written in
  Kotlin, Micronaut including native binary compilation
- [kotlin-step-function](kotlin-step-function) - it's a project unrelated to todo-app that uses AWS Step Functions with
  Kotlin and Micronaut
